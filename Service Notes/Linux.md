
## What is a Linux Service?  
Linux, a service is a program that runs in the background and performs essential tasks without needing the user to interact with it directly. These background programs are also called daemons.

# Think of services like workers doing specific jobs quietly while the rest of the system runs — for example:
- A web server service handles visitors coming to your website.
- An SSH service allows remote login from another computer.
- A database service stores and manages data for applications.


# Key Terms:  
- Daemon: A background process (usually ends in d, like sshd, httpd).
- Systemd: Modern service manager in most Linux systems.
- Service: A program that starts automatically or manually to perform a specific task.
