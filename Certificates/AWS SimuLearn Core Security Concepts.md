## 📘 AWS SimuLearn: Core Security Concepts
Awarded on 02 December 2025

**Overview:**  
AWS SimuLearn: Core Security Concepts introduced me to the essential security practices within AWS. I learned about Identity and Access Management (IAM), encryption, firewalls (security groups and NACLs), and monitoring tools like AWS CloudTrail. These concepts are key to protecting resources, managing access, and maintaining a secure cloud environment.
