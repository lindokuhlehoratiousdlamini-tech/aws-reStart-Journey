# 📘Building Generative AI Applications Using Amazon Bedrock
Awarded on 11 December 2025

**Overview:**

In this course, I learned how to build generative AI applications using Amazon Bedrock APIs and LangChain. I implemented use cases such as text generation, summarization, RAG, and question answering, built RAG applications with Bedrock Knowledge Bases, and created AI assistants using Bedrock Agents and tools.
