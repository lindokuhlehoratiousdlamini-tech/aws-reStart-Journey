# 📘Amazon Q Developer Getting Started
Awarded on 11 December 2025

**Overview:**

In this course, I learned how to use Amazon Q Developer, a generative AI–powered assistant that supports the full software development lifecycle on AWS. I explored its features, use cases, architecture, and costs, and set up an IDE to optimize code, modernize Java applications from Java 8 to Java 17, and implement new features using Amazon Q Developer
