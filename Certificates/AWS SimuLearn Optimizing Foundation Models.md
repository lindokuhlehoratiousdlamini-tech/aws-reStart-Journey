# 📘Optimizing Foundation Models
Awarded on 11 December 2025

**Overview**

In this course, I explored two techniques to improve the performance of a foundation model: Retrieval Augmented Generation (RAG) and fine-tuning also learned about Amazon Web Services services that help store embeddings with vector databases, the role of agents in multi-step tasks, define methods for fine-tuning an FM, how to prepare data for fine-tuning, and more.
