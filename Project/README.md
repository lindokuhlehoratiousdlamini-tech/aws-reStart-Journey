## Project 1: Static Website

## Nastro Bliss – AWS Static Website & Cloud Migration Project

I developed this project with my group as part of my AWS Cloud Practitioner journey. The goal was to build a static website for Nastro Bliss, a local restaurant, and prepare a presentation showcasing the benefits of migrating its digital presence to AWS. Nastro Bliss is a popular dining spot that faces challenges with managing customer bookings and orders. Their manual system often leads to mix-ups, double bookings, and inefficiencies. My solution was to design a simple, user-friendly static website hosted on AWS, while also demonstrating how cloud migration improves scalability, performance, and cost efficiency.

## Objectives
- Build a fully functional static website for Nastro Bliss.
- Host the website and assets on Amazon S3.
- Ensure the site is clean, responsive, and easy for customers to place orders or make bookings.
- Prepare a presentation highlighting the business and technical benefits of AWS migration.

## AWS Services Used
- Amazon S3 → Hosting the static website and storing images (menu photos, ambiance).
- Amazon CloudFront → Content delivery with low latency for global users.
- Amazon Route 53 → Domain management and DNS routing.
- Elastic Load Balancer (ELB) → Distributing traffic for high availability.
- Amazon RDS / DynamoDB → Managing customer and order data.
- AWS Lambda → Serverless compute for lightweight backend tasks.
- Amazon CloudWatch → Monitoring performance and usage.

## Project 2: 3D Architecture
## 3D E-Commerce Platform on AWS

## Overview
I built this project as part of my cloud architecture design journey. The goal was to design a next-generation 3D e-commerce web application that allows users to interact with 3D models of products—such as furniture, gadgets, and fashion items—before purchasing. With millions of users expected globally, my responsibility was to create an AWS-based architecture that is fast, highly available, secure, and cost-efficient.
## Objectives
- Design a scalable and resilient cloud architecture for a 3D e-commerce platform.
- Ensure high availability and fault tolerance.
- Optimize performance for smooth 3D rendering and quick page loads.
- Implement AWS security best practices.
- Control costs using auto-scaling, managed services, and monitoring.

## Project 3: Chatbot
This project is a chatbot developed by our group to provide interactive and intelligent conversations with users. It is designed to be simple, flexible, and easy to expand for different use cases such as customer support, learning assistance, or general conversation.
## Services Used in Making a Simple Chatbot
- Programming Language
- Amazon Lex
- Lambda
- S3

# Objective

The objective of this project is to design and develop a simple chatbot that can interact with users through basic text-based conversations. Our goal is to understand the fundamentals of chatbot development, including handling user input, generating appropriate responses, and working collaboratively as a team. This project also aims to improve our programming skills and introduce us to real-world application development using simple tools and technologies.

# Features
- Provides basic text-based conversation
- Responds to user input using simple rules or predefined responses
- Easy to use and understand
- Simple and clean code structure
- Easy to test and modify
- Supports group collaboration through version control
